# ABYSSINIA ONE

Animated static website concept for ABYSSINIA ONE.

- 21st.dev-inspired interaction language: Animated shader-inspired hero + feature bento
- Theme: Deep violet / cyan tech
- No external runtime dependencies
- Cloudflare Workers Static Assets ready
- Real business imagery can be added later under `assets/` without changing the layout system

## Run

Deploy with Wrangler using `npx wrangler deploy`.
